# mdpdf — Markdown to PDF Converter

## Overview

A fast, single-binary CLI tool written in Rust that converts Markdown files to beautifully typeset PDFs. Primary use case: converting Markdown files generated by Claude into clean, professional PDFs.

## Goals

- **Simple CLI** — `mdpdf input.md` produces `input.pdf`
- **Great typography out of the box** — Inter for body text, JetBrains Mono for code blocks, proper kerning/ligatures/justification
- **Full CommonMark + GFM support** — tables, task lists, strikethrough, autolinks
- **Syntax-highlighted code blocks** — fenced code with language-aware highlighting
- **Zero runtime dependencies** — fonts embedded in the binary

## Non-Goals

- WYSIWYG editing or live preview
- HTML/CSS-based rendering pipeline (no headless browser)
- Plugin/extension system
- LaTeX math rendering (possible future addition)

## Architecture

```
┌────────────┐    ┌─────────────┐    ┌──────────────┐    ┌──────────┐
│  Markdown  │───>│   Parser    │───>│  Typst       │───>│  PDF     │
│  (input)   │    │  (pulldown- │    │  Markup      │    │  (output)│
│            │    │   cmark)    │    │  Generator   │    │          │
└────────────┘    └─────────────┘    └──────────────┘    └──────────┘
                                           │
                                     ┌─────┴──────┐
                                     │   Typst    │
                                     │  Compiler  │
                                     │  (library) │
                                     └────────────┘
```

### Pipeline

1. **Parse** — `pulldown-cmark` parses Markdown into an event stream (CommonMark + GFM extensions)
2. **Transform** — Convert the event stream into Typst markup with embedded styling
3. **Compile** — `typst` crate compiles the markup to PDF, with Inter and JetBrains Mono fonts provided via a virtual file system

### Why Typst?

Typst is a modern typesetting engine written in Rust that produces publication-quality PDFs:

- **Knuth-Plass line breaking** — optimal paragraph justification, same algorithm as TeX
- **OpenType features** — proper kerning, ligatures, and font metrics for Inter
- **Rich layout primitives** — tables, code blocks, block quotes all handled natively
- **Native Rust library** — no subprocess, compiles directly in-process
- **Fast** — compiles documents in milliseconds

### Key Crates

| Crate | Purpose |
|-------|---------|
| `pulldown-cmark` | Markdown parsing (CommonMark + GFM extensions) |
| `typst` | PDF compilation with professional typesetting |
| `typst-syntax`, `typst-eval` | Typst document construction |
| `syntect` | Syntax highlighting for code blocks |
| `clap` | CLI argument parsing |

### Font Strategy

Embed Inter and JetBrains Mono as TTF files, served to the Typst compiler via a custom font provider. The fonts ship inside the binary — no system font lookup needed.

| Context | Font | Weight/Style |
|---------|------|-------------|
| Body text | Inter | Regular (400) |
| Bold text | Inter | Bold (700) |
| Italic text | Inter | Italic (400i) |
| Bold italic | Inter | Bold Italic (700i) |
| Headings | Inter | Bold (700) |
| Code (inline & block) | JetBrains Mono | Regular (400) |

## CLI Interface

```
mdpdf [OPTIONS] <INPUT>

Arguments:
  <INPUT>          Markdown file path (use "-" for stdin)

Options:
  -o, --output <FILE>      Output PDF path [default: <input-stem>.pdf]
  -t, --title <TITLE>      PDF document title metadata
      --font-size <PT>     Base body font size [default: 11]
      --page-size <SIZE>   Page size: letter, a4 [default: letter]
      --margin <MM>        Page margins in mm [default: 25]
  -h, --help               Print help
  -V, --version            Print version
```

### Examples

```bash
# Basic conversion
mdpdf notes.md

# Custom output path
mdpdf notes.md -o report.pdf

# Pipe from stdin
cat notes.md | mdpdf - -o output.pdf

# A4 with larger font
mdpdf notes.md --page-size a4 --font-size 12
```

## Markdown Feature Support

### MVP

- Headings (H1–H6) with scaled font sizes
- Paragraphs with justified text and proper line breaking
- **Bold**, *italic*, ***bold italic***
- Inline `code` with monospace font + light background
- Fenced code blocks with syntax highlighting
- Unordered lists (nested)
- Ordered lists (nested)
- Horizontal rules
- Block quotes (indented, with left border accent)
- Links (rendered as colored text with URL in parentheses)
- GFM tables
- Task lists (checkboxes)
- Strikethrough text

### Future

- Table of contents generation (`--toc` flag)
- Page numbers in footer
- Custom theme files
- Header/footer templates
- Multi-file input (concatenate)
- Watch mode (`--watch`)
- Image embedding

## Error Handling

- Missing input file → clear error message with path
- Malformed Markdown → best-effort rendering (Markdown is lenient by design)
- Output write failure → error with path and OS error message
- Typst compilation error → surface the Typst diagnostic

## Testing Strategy

- **Unit tests**: converter produces correct Typst markup for each Markdown element
- **Integration tests**: render fixture `.md` files to PDF, verify PDF is valid and non-empty
- **Manual review**: visual inspection of output for typography quality
